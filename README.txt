DR. RAJ BALDANIYA – CLINICAL POCKET APP

This is a Progressive Web App (PWA).
Features:
- Search all clinical notes
- Add/edit/delete notes
- Favorites
- Custom categories
- Dose mathematics
- 4-2-1 maintenance-fluid mathematics
- Dose-to-volume calculator
- Local browser storage
- Offline caching after first successful load
- iPhone/iPad Add to Home Screen support

IMPORTANT:
This app is a personal knowledge tool, not a clinical decision-support system.
Verify current guidelines and drug references before patient care.
Do not store identifiable patient information in this simple app.

To install:
1. Host this folder on an HTTPS website.
2. Open it in Safari on iPhone/iPad.
3. Tap Share -> Add to Home Screen.
For Android, use the browser's Install/Add to Home Screen option.
